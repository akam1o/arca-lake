# 0.1.0 readiness

Tracking document for the first experimental release, 0.1.0. It records,
per item, what was checked, on which commit, with what result and what is
left. [The experimental checklist](experimental-checklist.md) is a
historical snapshot of an earlier phase and is not evidence for 0.1.0.

0.1.0 is **experimental**: for evaluation and development, not for
production data. Nothing here claims full S3 coverage, support for
platforms other than Linux x86_64, or performance at scale.

Kinds: **Requirement** (must hold for publication), **Limitation**
(known, disclosed, does not block), **Follow-up** (later release).

Status: final candidate binary built from `45ca5f3` (tree of main
`6b714fe`; later commits change the validation driver and documentation
only). The tag commit is fixed after the last results; its archive is
rebuilt and its binary compared. Updated as items are verified.
